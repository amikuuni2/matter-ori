# Matter Ori
A lightweight English-language 10x10 block puzzle game.

## Run
Open `index.html` in a modern browser. For development, a local HTTP server is recommended.

## Controls
1. Select one of the three pieces.
2. Click/tap a board cell to place its top-left anchor.
3. Complete a full row or column to clear it.
4. The game ends when none of the remaining pieces can be placed.

## Microsoft Store preparation
This folder is the game source, not a signed Store package. Before submission, wrap it as a Windows/PWA app, add Store artwork/icons, set your publisher identity/package name from Partner Center, test the package, then submit it through Microsoft Partner Center.

## Notes
- UI language: English
- Offline gameplay
- Best score is stored locally
- No ads, analytics, external libraries, or copyrighted third-party assets
